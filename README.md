# AmericanAirlines_FuelConsumption_Analaysis
Quick data analysis project suing Python to analyze the annual fuel consumption for the wide-span aircraft in the American Airlines fleet.
I used BeautifulSoup to scrap the data, Pandas and matplotlib to plot the graph.

#Source https://web.mit.edu/airlinedata/www/2020%2012%20Month%20Documents/Aircraft%20and%20Related/Carrier%20Operating%20Stats/American%20Airlines%20Aircraft%20Operating%20Statistics-%20Actuals.htm.
