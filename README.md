# AmericanAirlines_FuelConsumption_Analaysis
Quick project on Python using BeautifulSoup and Pandas to scrap and then plot the annual fuel consumption. The data cames from MIT website: https://web.mit.edu/airlinedata/www/2020%2012%20Month%20Documents/Aircraft%20and%20Related/Carrier%20Operating%20Stats/American%20Airlines%20Aircraft%20Operating%20Statistics-%20Actuals.htm  widebody aircraft
