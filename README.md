# AmericanAirlines_FuelConsumption_Analaysis
Quick project on Python using BeautifulSoup and Pandas to scrap and then plot the annual fuel consumption for the wide-body aircrafts, indicated with 'W' on the file. The data is publicly available at the MIT website: https://web.mit.edu/airlinedata/www/2020%2012%20Month%20Documents/Aircraft%20and%20Related/Carrier%20Operating%20Stats/American%20Airlines%20Aircraft%20Operating%20Statistics-%20Actuals.htm.
